# Последний остров 3D

Исходный проект Godot 4 для Android и ПК. Полный архив проекта: `LastIsland3D_Android_Project.zip`.

Откройте `project.godot` в Godot 4.3 или новее. Инструкция по экспорту APK находится в `README_RU.md` внутри архива.

Статус: стартовый игровой прототип; APK пока не собран и не проверен на устройстве.
